## v0.2.0 «Инструменты» · 2026-09-04 · Спринт 1

**Добавлено**
- `core/dsp.mjs`: БПФ radix-2, Ханн, автокорреляция через БПФ, Левинсон–Дурбин, LPC-огибающая.
- `prosodyTool` (ХРОНОС, харнесс типа DSP): F0 автокорреляцией с октавной проверкой, вариативность F0, RMS, паузы (−35 дБ от пика), темп онсетов, F1–F4 по LPC (порядок 2 + sr/1000), центроид, наклон, HNR, джиттер/шиммер по циклам (метки — восходящие нули), спектрограмма 0–5 кГц 600 × 128; golden: тон 150 Гц → 150,00; тишина → 100 % пауз; шум → HNR −11 дБ; джиттер ±1 % → 0,0204; гласный 500/1500/2500/3800 → 503/1514/2504/3802 Гц; 44,1 и 48 кГц.
- `lexisTool` (ЛЕКСИС): местоимения, модальность, Zimbardo-прокси 🔵, спикер-баланс, инициативность 🔵, тепловая карта 24 ч по меткам `[HH:MM]`/ISO; golden с ручным счётом долей; RU/UA/EN.
- `phonoSemTool` (VAAL-lite 🔵): 25 шкал через заменяемые `PHON`/`SCALE_MAP`, полярность, значимые |d| > 0,12 / |z| > 1, три блока признаков, контент-анализ 8 категорий 🔵, Плутчик 8, Белянин 6, TTR/hapax; автоопределение RU/UA/EN.
- `groundingClassifier` (ЦЗИ-8 🔵): K1–K8 по словарям маркеров, профиль долей, разрыв (< 5 %), модусы А/Б/В/Г через `LIBERTY_MAP`; golden 8 × 10 — 100 %; монотонность; инвариантность к перестановке.
- `scaleScorer`: открытые ключи PHQ-9, GAD-7, TAS-20, MBI, SCL-90-R, IPIP-50; Рокич (ранги); Gallup-34 (импорт рейтинга → домены); неполный опросник → ⛔ без импутации; проприетарные ключи → ⛔ с причиной; флаг кризиса по PHQ-9 п. 9.
- Интерфейс: экран «Речь» (Spectrogram canvas по Приложению D, Envelope, три прокси-чипа 🔵, 25 шкал VAAL с полярностью, радар Плутчика, Белянин, ЛЕКСИС, радар Zimbardo, Heatmap24), экран «Тесты» (PHQ-9/GAD-7 формы, светофор, кризисный блок, импорт JSON), ЦЗИ-8 в профиле по данным классификатора, реальные таймкоды в демо-транскрипте, загрузка аудио через `<label>` + Web Audio (офлайн-декодер), синтетический тон-демо.
- Конвейер: L1 теперь 8 шагов (intake · cascade · chronometry · memory · prosody · lexis · vaal · grounding · scales); карточки 🟢/🔵/⛔.
- Реестр параметров: 142 записи. Раннер пишет промежуточный отчёт перед UI-харнессом.

**Честные ограничения (⛔)**
- `PHON`, категории контент-анализа, имена контуров K2–K7 и карта модусов — реконструкции 🔵; точные таблицы методологии подставляются без изменения логики.
- Диаризации нет: полоса спикеров на спектрограмме ⛔; STT нет — семантика только по транскрипту.
- Просодика считается в главном потоке (~0,15 с на секунду аудио); лимит 90 с; Worker — следующий шаг.
- Ключи 16PF, IST, Белбин, Леонгард, Мадди не загружены.
- Агенты L2 и синтез L3 — Спринт 2.
