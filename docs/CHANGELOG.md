# CHANGELOG

## v0.1.0 «Каркас» · 2026-09-04 · Спринт 0 (+ первые инструменты Спринта 1)

**Добавлено**
- `CLAUDE.md` — мастер-промпт v1.0 как системная инструкция репозитория.
- Ядро: `Param`, `EventBus`, `Scp` (иммутабельный, аудит-трейл, round-trip).
- Схемы: `Scp.v1`, `Param.v1`, `HarnessPassport.v1`, `AgentCard.v1`, контракты in/out пяти инструментов.
- Движки с зелёными харнессами: `cascadeEngine` (обе формы, golden «Константин» B = 0,34), `stimulusGate` (15–25 Гц блок, 85 дБ, стоп < 100 мс, нет API обхода), `chronometry` (240 мин ≈ 39,4 лет), `gccEngine` (SMFK-100, фикстура 0,842491 байт-в-байт), `memorySearchTool` LOCAL (hashing + триграммы; «выгорание, нет смысла» → C002; ◇ MCP-SWAP).
- Харнесс-фреймворк: `Harness`, `Rng` (mulberry32), сканер NaN/диапазонов, раннер с отчётом JSON/MD; UI-харнесс (сканер 4.9 + сборка + рендер в 3 вьюпортах + сценарий + round-trip + размер).
- Реестры: 51 агент, 13 инструментов, 113 параметров, 4 модели (ID сверены), 35 рамок.
- Интерфейс: токены 4.1, 13 компонентов, галерея с фикстурами пусто/один/экстремум/NaN, оболочка Телефон/Студия/Печать, Dynamic Island (aria-live, long-press → ⌘K), композер (скрепка через `<label>`), состояния на каждом экране, гейт-панель, кризисная кнопка, память LOCAL/MCP, реестр агентов с редактором задач, настройки (локаль, модель, экспорт/импорт/печать, гейты только просмотр).
- Single-file сборка `dist/atmaraksi-os.html` (230 КБ, офлайн).

**Честные ограничения (⛔)**
- Агенты L2 и синтез L3 (Reflector/TheraNavigator/Judge) не вызываются: нет харнесса типа llm-agent — Спринт 2. Конвейер выдаёт детерминированный отчёт 🟢/⛔.
- `prosodyTool`, `lexisTool`, `phonoSemTool`, `groundingClassifier`, `scaleScorer`, `ppgTool`, `riskEngine`, `fusionEngine` — `hidden_by_harness` (Спринты 1, 4, 6).
- Экраны Речь/Тесты/Разум/Тело/Нарратив — пустые состояния с описанием полного пайплайна.
- Реестр параметров 113 из целевых 300+.
- Демо-транскрипт и корпус памяти — синтетические, не данные клиентов.
